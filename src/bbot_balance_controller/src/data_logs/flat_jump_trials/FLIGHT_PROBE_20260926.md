# 平地飞行执行器辨识（2026-09-26）

- 目标：辨明空中后仰对车轮、双髋、双膝小幅命令的闭环响应；不改正常跳跃控制。测试专用脉冲只在仿真 FLIGHT 安全窗口 0.08–0.12 s 生效，车轮 ±0.15 m/s、双髋或双膝各 ±1 Nm，保持原限幅；单独侧车 CSV 记录实际下发量与传感器时间戳。
- 采集：三轮交替基线/正/负配置共 21 跳；五跳因起跳前超时或缺少有效飞行段而补跑，共 26 次启动。基线记录中激励恒为零；有效车轮脉冲实际下发约 ±0.15 m/s，有效腿脉冲约 ±1 Nm。完整跳跃验收仍未通过，本实验不以触地恢复成功为辨识有效条件。
- 判读：以脉冲前后角速度变化的差值及同轮正负配对比较；入段 pitch 差超过 0.06 rad 或角速度差超过 0.35 rad/s 的配对剔除。车轮 3/3 配对可比，但响应差方向不一致（平均 +0.052 rad/s、标准差 0.268）；髋 2/3、膝 2/3 配对可比，均未达到预设三组重复要求。两组可比髋响应同向只属线索，且包含正常轮控的闭环补偿，不能当作裸关节力矩系数。
- 结论：本轮辨识 **不确定**，不得据此反转力矩符号或加大单一增益。主要障碍是离地初态波动和偶发初始平衡超时；下一步应先实现可重复的离地状态/配对筛选，再做同类因果试验。临时激励路径按计划撤回，保留原始侧车数据与离线判读脚本。
- 撤回验证：控制器、launch、试验入口及临时单测中已无激励引用；重新构建两个包成功，14/14 单测通过。普通平地跳跃烟测完成但失败（锁存口径最高点增量 0.257 m、落地后不可恢复后仰）；自适应 LQR 独立运行约 21 s 仿真时间，产生 4029 行日志且姿态保持约 -0.008 rad。本轮没有修改正常控制增益。
