# 平地跳跃落地失败定位（2026-09-27）

范围：默认参数、常驻发令、三次有效飞行；仅分析和节拍日志增强，未修改控制增益或落地状态机。三次均以 `FAIL_landing_unrecoverable_pitch` 结束。

## 观测事实

- `TOUCHDOWN_BUFFER` 入口的机身俯仰为 **−0.382、−0.438、−0.454 rad**，角速度为 **−1.33、−1.42、−1.46 rad/s**。进入前 50 ms 已是 **−0.317 至 −0.382 rad**，仍以 **−1.43 至 −1.58 rad/s** 后转。后仰在空中形成，并非 CATCH 首次造成。
- 三次在进入缓冲后约 0.10 s，整机前向速度估计均翻为约 **−1.2 至 −1.4 m/s**；约 0.25 s 轮速升至 **+30 rad/s** 上限，俯仰仍持续恶化。仅增强 CATCH 轮速需求未必有执行空间。
- 从 FLIGHT 起点到约 0.25 s，空中俯仰参考保持约 **+0.065 至 +0.085 rad**，实测俯仰却降到约 **−0.23 至 −0.29 rad**、角速度约 **−1.7 至 −1.9 rad/s**；误差方向明确。
- 在 FLIGHT 后约 0.25 s，空中轮速目标约 **+0.44 至 +0.48 m/s**，实测轮速乘 0.07 m 半径约 **+0.44 至 +0.47 m/s**，两者接近；物理轮速上限对应约 2.1 m/s，故当时并非轮速幅值已满。速度型轮控此时可能缺少持续纠偏的速度差，但无轮电机实际力矩日志，不能断言力矩余量或根因。
- 缓冲状态入口比接触消息重现早约 0–10 ms，强支撑 IMU 比力约在入口后 15 ms 才出现；接触消息的 wrench 为零，不可把它用作精确接触力。不能把状态入口误写成经力阈值验证的物理撞地时刻。

## 判断与下一步

优先验证**空中姿态纠偏能力**，而非先放宽推地姿态门控或继续提高落地 CATCH 命令。一个可检验的单变量候选是让起跳时锁存的负轮速基线在空中逐步退出，以便后仰时轮速目标有更大正向加速差；这只是机制假设，须保持轮速/角度安全限幅，并与现行基线做配对试验。验收同时看起跳高度、前速、触地前俯仰及角速度、轮速、触地后是否真正回到 Effort 平衡，不能只看某一帧姿态改善。
