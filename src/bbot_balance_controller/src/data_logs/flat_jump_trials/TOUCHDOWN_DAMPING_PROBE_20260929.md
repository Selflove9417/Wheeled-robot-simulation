# 平地跳跃落地缓冲阻尼单变量复核（2026-09-29）

范围：默认无载荷平地跳跃。Gazebo 原生接触消息缺少 wrench，因此本轮只用姿态、轮速、关节及质心状态；`F_z` 是控制器**请求的支撑力**，不是实测接触力。

## 假设与操作

最新默认样本 `touchdown_hip_guard20_baseline_20260929/trial_01_20260929_194455` 触地后 0.05 s 请求总支撑力 415.4 N，膝命令 −57.3 Nm，后 0.08 s 髋角到 1.570 rad 硬限位。为检验过强竖直缓冲是否参与早期关节冲击，只把 `D_Z_BUFFER_` 从 75 降至 50 N·s/m。预测：同等触地状态下，早期 `F_z`、髋角峰值降低，且后续 COM lean 不恶化。没有调整髋 PD、轮控、落点或自适应控制参数。

构建成功；`ground_joint_pd`、`torso_pitch_control`、`jump_phase_control`、`jump_regression`、`centroidal_capture` 五项测试全部通过。运行两次默认平地试验，分别保留于 `touchdown_damping50_20260929/` 与 `touchdown_damping50_repeat_20260929/`。

## 处理与后续

50 N·s/m 未达到落地恢复目标，已撤回并重建；默认 `D_Z_BUFFER_` 仍为 75 N·s/m。撤回后上述五项测试再次全部通过。未删除任何试验数据，未清理既有进程，未改自适应控制默认参数。

接下来优先缩小 FLIGHT 入段的髋膝角与角速度波动，随后只对 **触地前** 的角动量或落地几何提出一个可验证变量。当前证据不支持继续靠单纯增大髋力矩或减小落地竖直阻尼解决后倒；也不能把缺失的接触力解释成零力。
