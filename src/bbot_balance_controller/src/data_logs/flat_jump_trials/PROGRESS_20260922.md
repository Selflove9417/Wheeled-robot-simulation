# 平地滚动跳跃阶段记录（2026-09-22）

## 目标

仅验证平地滚动起跳：目标跳高 `0.20 m`，起跳前向速度验收范围 `0.35–0.55 m/s`，落地后恢复 Effort 平衡。

## 已处理

- 使用整机质心速度判断起跳，并锁存首次有效离地速度。
- 推力达到目标速度前约 `14%` 开始 40 ms 单调卸载，减少离地确认期间的多余冲量。
- TUCK/EXTEND 使用可行轨迹和反作用安全处理，避免高速关节瞬时反向。
- 落地采用 wheel-first 几何：`L_RETRACT=0.66 m`、`L_TOUCH=0.69 m`、捕获增益 `1.60`。
- 反向落地刹车改为单次触发；姿态不可恢复时提前退出，避免刹车反复触发。
- 推地膝关节制动加入髋关节反作用补偿。
- 将空中轮控重构成独立可测试函数 `flight_wheel_target`，默认 `air_wheel_sign` 由 `+1.0` 修正为 `-1.0`，ATTITUDE_ARREST 关节制动前馈使用统一符号映射，消除空中反作用力矩打架。
- 在平地试验脚本与 launch 中增加 `--air-wheel-sign` 透传参数，并在 `test_rolling_jump.cpp` 中补充方向与前馈协同单元测试。
