# 平地跳跃基线可重复性（2026-09-26）

固定默认配置：目标高度 0.20 m、起跳前速 0.45 m/s、空中轮符号 -1、EXTEND 阻尼 0.45、推地轮减速 8.0。6 次启动均通过初始平衡与四类采样新鲜度检查，故在 6/12 有效样本处按计划停止；6/6 正常进入 TUCK/EXTEND，但完整验收 0/6，均为 `FAIL_landing_unrecoverable_pitch`。2/6 跳高超出 0.23 m，4/6 起跳前速超出 0.55 m/s，起跳竖速 6/6 在验收范围内。

- 命令前状态几乎重合：pitch 极差 <0.001 rad，角速度极差 <0.001 rad/s，质心前速极差约 0.001 m/s。命令前快照到 PRE_JUMP 首帧的间隔却为 750–1301 ms；此间包含命令行发布进程启动，不能直接称作 ROS 消息延迟。
- PRE_JUMP 左轮速极差已达 0.138 rad/s；THRUST 为 0.987 rad/s。进入 FLIGHT 时，俯仰/角速度按旧门槛 15/15 对均可配对，但左轮、左髋、左膝速度极差分别为 3.268、2.117、1.509 rad/s。因此“姿态可比”不等于完整离地机械状态可比。
- 按预设核心状态比较带，FLIGHT 的质心前速极差 0.111 m/s 首次越过 0.10 m/s；触地俯仰范围 -0.423 至 -0.294 rad，触地前质心相对轮轴位置约 -0.283 至 -0.229 m。FLIGHT 四类采样最大龄 16 ms，未发现明显断流。极差与先后次序只定位排查入口，不能证明哪一项导致后仰。

结论：下一轮先核查跳跃命令接收时间、PRE_JUMP/SQUAT→THRUST 的轮腿状态、THRUST→FLIGHT 的采样和执行器命令时序；在完整离地状态可重复前，不据此调力矩符号、单一增益或落地限幅。原始日志、逐次阶段快照和 `analyze_flat_jump_repeatability.py` 可复算本报告。
