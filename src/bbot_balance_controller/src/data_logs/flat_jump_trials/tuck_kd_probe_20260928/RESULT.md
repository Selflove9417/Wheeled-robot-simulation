# 2026-09-28 TUCK 轮控增益交替对照

仅在平地 velocity 轮控的观测模式中，将 TUCK 角速度反馈增益由默认 `0.45` 改为 `0.90`；顺序为 A–B–B–A。起跳、腿轨迹、EXTEND、落地控制和安全门槛均未调整。四次均进入飞行，均以 `FAIL_landing_unrecoverable_pitch` 结束。

| 试验 | TUCK Kd | FLIGHT 入段角速度 (rad/s) | EXTEND 入段角速度 (rad/s) | 触地俯仰/角速度 (rad, rad/s) | 锁存口径质心高度 (m) |
|---|---:|---:|---:|---:|---:|
| A1 | 0.45 | +0.406 | −0.805 | −0.387 / −1.339 | 0.258 |
| B1 | 0.90 | +0.458 | −0.863 | −0.366 / −1.338 | 0.213 |
| B2 | 0.90 | +0.299 | −0.909 | −0.513 / −1.585 | 0.255 |
| A2 | 0.45 | +0.432 | −0.708 | −0.303 / −1.190 | 0.218 |

两个 B 样本的 TUCK 轮命令均出现正值，而两个 A 样本保持负值，说明试验参数确实作用于空中轮控。四次飞行最大轮速均低于 10.1 rad/s，没有触及 30 rad/s 关节上限，也没有触发保护展腿。

但 B1 对 A1 的 EXTEND 入段角速度略更负，触地角速度基本相同；B2 对 A2 的 EXTEND 入段与触地角速度均更负。B2 的 FLIGHT 入段角速度和前向速度也不同，因此不能把全部差异归因于增益。当前数据不支持将 `0.90` 设为默认值，也不支持继续单向加大 TUCK D 增益。两组各两次，只能作为有界诊断，不能作统计性结论。

下一步应检查 FLIGHT 入段至 TUCK 结束的腿部轨迹速度、髋膝力矩与机身角动量交换，尤其是约 60–70 ms 内角速度由正转负的机制；在明确单一可检验变量前，保持本轮控制参数不变。
