# 本轮复盘：提前接地构型未通过，已默认关闭

本轮实际做了两组RTF1正常速度单跳，完整验收均FAIL，0次正常FLIGHT。没有修好落地，也没有验证起跳后翻动量降低。原先能完成跳跃但会后退的默认恢复版保持不变；没有启动连续两跳或追加参数组。

## 为什么调整方案

上轮独立参考版离地的七体模型总后翻角动量约1.718kg·m²/s，空中200ms仍约1.695，机身陀螺仪接近零遗漏了腿部角动量。原本拟在推地末段前移质心，但13个真实样本的髋形状PD原始值均低于−3/0Nm限幅下界：−34.99到−13.65Nm。再降低髋参考0.13rad不会改变任一限幅后的PD。这证明该命令路径没有余量，不是新物理轨迹的预测。

因此在独立reference controller提前做SQUAT→THRUST接地构型连续塑形，保留原推力脉冲、姿态/形状增益、关节/速度/扭矩/位置命令上限、轮控、飞行策略、动作时长和RTF1。第一次前置30mm，第二次只把同一目标改为10mm。

两次都没有正常FLIGHT/TUCK/EXTEND或触地恢复，摘要中的apex_height_delta只是旧FK类指标，不能冒充跳高；takeoff/landing零值属于无有效事件的占位，不代表零后退、竖直着陆或已通过。

## 记录和验收

## 收尾版本

独立参考版 `reference_ground_launch_shaping` 默认false。SQUAT、速度前视、Effort等待、THRUST seed及名义推地均回原中立IK；Effort SQUAT恢复nullptr构型覆盖。CSV新增启用标记，关闭时塑形有效性及目标诊断值为0。30mm/10mm失败候选快照、日志、版本hash及明确启用的实验代码保留。

最终构建成功，18项相关检查通过。完整真实动作的通过仍必须依赖物理实跑；关闭开关后的独立reference程序本轮没有再次仿真，只核对代码路径等价和编译/测试。14个保护项（默认控制源码与二进制、profile、默认世界、原接触记录器、默认运行入口和6个MPC文件）校验均不变。两次启动日志中的7个进程PID分别全部退出，没有结束无关进程，没有推送或开启自动续跑。

30mm候选18个冻结项在实跑后全部匹配。10mm实跑使用冻结源码快照及二进制；实跑结束后才加入默认关闭开关，因此post-run source校验仅controller.cpp不同，二进制及其余17项仍匹配；该差异留在single_10mm_post_run_check.json，不虚报全部运行后源码不变。收尾重建的二进制另见delivered_manifest.json。

## 后续优先级

接地构型和平衡参考需要一起计算，并覆盖实际启动高度及原位置命令斜率。先在原速度、原门槛下建立可保持且能放行推地的构型，再比较同stamp真实离地模型总H与原生首次触地姿态。先不要提高跳高目标，也不要靠放宽门控、延长下蹲或增大扭矩上限掩盖这个耦合问题。

默认启动仍是工作区根目录 `./run_complete_jump_demo.sh`，它能完成跳跃但落地后退的已知问题仍在。
