# 2026-09-28 TUCK 时长诊断

离线检查既有八份日志：FLIGHT 入段至 TUCK 入段约 10–15 ms，角速度降低约 `0.17–0.47 rad/s`；TUCK 至 EXTEND 约 60–65 ms，继续降低约 `0.85–1.07 rad/s`。同期轮速显著变化，关节角位移较小。`actual_tau_*` 是控制器下发命令；`JointState.effort` 在该窗口为零，不能据此当作可靠的实测关节力矩或证明角动量来源。

`0.08 s` 两次均通过轨迹预算并完成展腿，飞行轮速峰值均低于 `8.1 rad/s`，未触发保护展腿；但 EXTEND 入段后转角速度没有在两次试验中一致减轻，落地恢复也未成功。因此保持默认 `0.06 s`，不继续延长。下一步应先验证轮速命令到实际反作用力矩的方向和滞后，再判断腿轨迹是否值得单独重塑。
