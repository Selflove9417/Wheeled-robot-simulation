# 阶段一：完整实际输入与受保护接地交接

结论：**阶段一输入门通过；模型响应、正常刹停和跳跃均未通过验收。**

本轮问题：在分配器关闭、有界 P 轮速增益固定 1.0、速度轮执行器 inactive 的条件下，能否从 Position 稳定站立切到 Effort 支撑，并记录完整、可配对的六路实际物理输入？只执行一次固定地面协议，不发送 J 或 jump_cmd。

实跑 **1 次**，腾空跳跃 **0 次**，跳跃达标 **0 次**。净空、首触、缓冲、后退、12 秒跳后保持指标均为无效/未测，不能由站立结果代填。

## 固定条件与实际结果

- 世界 `native_command_observation_world.sdf`，物理步长 1 ms、配置实时倍率 1.0。未改动作速度或力矩限制。
- 唯一轮执行器为 wheel_effort_controller，diff_drive_controller inactive；唯一 P 伺服启动参数 `--gain 1.0`，轮速度目标 ±30 rad/s、轮力矩 ±10 Nm。
- 启动采用原 100 个物理步限额内的共享门：40 个 1 ms 步后通过；两次不同时间传感器/命令记录及实际 controller_manager 状态已核验。
- 6.545 s 请求 enter_effort；7.048 s 连续新鲜状态/双轮支撑准入后预装 Effort 支撑并请求严格切换；7.058 s 确认切换。等待期间仍保持 Position 支撑。
- 切换后连续稳定，再预先冻结 **[9.553, 14.553) s** 五秒验收窗；没有按模型误差或成功片段重新选择窗口。
- 窗内 **5000/5000** 原生物理帧包含有效六路 BeforePhysics JointForceCmd、关节 before/post q/v、双轮合法地面接触、两轮原生位姿、机身速度及相应控制状态。共 **30000/30000** 有效执行器步，缺失值保持无效/NaN，未补零。
- 原生九自由度消息同窗 **5000/5000** 完整：q/v/before_v mask 511、input mask 63；没有消息缺步，九自由度 post→next-before 速度最大差 **0**（原限值 1e-9）。
- 无时钟回退、重复物理身份、错配或 1 ms 步长缺口；窗口全程双轮接触，没有单轮支撑、离地、关节限位或模式回退。
- 窗内控制器 pitch 0.06135–0.07009 rad、|pitch_rate| 最大 0.008365 rad/s、|COM 前向速度| 最大 0.03408 m/s，满足原启动静稳门。原生模型 roll 为 -0.07009–-0.06135 rad，符号与控制器 pitch 相反；二者明确分别记录，不能混用于落地验收。
- 窗内物理输入髋绝对值最大 0.743521 Nm、膝 15.396497 Nm、轮 0.041526 Nm，均未越过 BALANCE 髋 75/膝 60/轮 10 Nm 限制。左右轮各有 1000 条有效伺服发布。
- 控制仿真/墙钟间隔中位数约 5 ms；个别控制间隔为 10 ms，物理步仍为 1 ms，所有窗口控制样本年龄均在原审计限值内。

## 发布、生效与物理响应

发布日志记录调用 API 前后的仿真时间与稳态墙钟时间，文件写入/flush 在发布之后，不再把日志开销当作发布延迟。窗口 1862 次控制器发布调用，调用墙钟耗时最大 47998 ns，仿真调用区间最大 1 ms。

全记录有 11164 个可解释的唯一力矩匹配，观测匹配偏移中位数 1 ms；122 条重复值事件保留歧义。原生 BeforePhysics 输入与同物理步响应完整配对。**这是观测延迟，不能作为保证延迟或制动包络常数。** `input_latency.csv` 给出调用区间对应的上下界；同刻/重复值不声称零延迟。

初始化 Position 阶段共 7048 个对应物理帧，腿部力输入缺失继续标无效，与五秒 Effort 验收窗分开。全程输入覆盖率约 68.15%不是窗口覆盖率；五秒窗口是100%。未把 Position 样本伪装成完整六路实际输入。
