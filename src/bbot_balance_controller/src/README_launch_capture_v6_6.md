# v6.6 推地收尾与落地持续捕获

本轮使用 2026-09-06 16:51 的日志。空中控制和地面离散关节反馈保留。

## 实测问题

- 7.342 s 世界上升速度 1.903 m/s，但随后又从刹腿转回推地，7.406 s 膝速度
  达到 -10.27 rad/s，行程保护把推力切至零。真正进入 FLIGHT 为 7.515 s，
  此时世界上升速度只有 0.428 m/s。
- 7.441 s 两轮净空已约 27 mm，7.460 s 增至 38 mm；单次原始加速度变化却
  将确认计数清零，直到后续采样才确认离地。
- 8.355 s 从 CATCH 转 PREPARE 时，车轮仍以约 -0.496 m/s 后退、命令为 +0.588 m/s。
  随后再次后仰，PREPARE 仍保持，轮指令卡在 +0.8 m/s，未返回捕获。

## 修改

1. 推地后段世界速度达到目标的 95% 后锁存收尾，40 ms 内平滑撤去该次推进力。
   速度回落不再触发新的补推脉冲，末段刹腿也不因速度回落而撤销。
   该状态不代替实际离地确认；关节行程保护、力矩限制保留，不增加峰值推力。
2. 两轮对齐净空达到 20 mm 后允许连续几何证据确认离地，不由单次 IMU 内部冲击否决。
   普通 12 mm 净空仍要求失重，仍禁止同一传感器帧重复计数，仍需要两轮同时离地。
3. CATCH 退出必须姿态、角速度、预测倾角、实际轮速和轮指令同时较小，持续 120 ms。
   原来只需要两次控制循环中的姿态条件。
4. PREPARE/BRAKE 阶段出现向外倾倒趋势时，清除制动阶段状态并返回 CATCH；
   不改落地点位置参考，不把当前轮速加余量当作新目标，避免累积轮速。
5. 仅地面 CATCH 在明确发散时把轮指令饱和边界从 ±0.9 平滑放宽，最大 ±1.5 m/s；
   捕获反馈增益和输出变化率不变，空中轮控仍使用原边界。

新增启动标记 `[launch-capture-v6.6]`，再次捕获日志 `[RECAPTURE]`，CSV增加
`thrust_release_active,thrust_release_blend,catch_stable_time`。

离线回归覆盖收尾不重新加力、撤力边界连续、行程保护保留、明确净空抗单次冲击、
记录中的后退状态不得退出捕获，以及前后方向的再次捕获条件。这不等同于完整Gazebo
跳跃验证。代码修改后不自动启动仿真，留给用户执行。
