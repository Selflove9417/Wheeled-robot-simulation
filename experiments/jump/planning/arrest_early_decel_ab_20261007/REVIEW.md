# ARREST早期腿部制动单逻辑A/B物理验证

2026-10-07。目标仅为检验：减弱离地后最初几十毫秒的腿速变化，是否能减弱/推迟持续负pitch_rate。未处理高度，未修改正式控制器。

## 验收结论：不采用候选，默认原实现保持

完成固定交替顺序B1/T1/B2/T2/B3/T3，共**6次实跑、6次腾空、6次落地**，全部完成真实首触后至少20秒记录并回到BALANCE。没有追加失败替代样本或调参。另有1次本地通信被受限环境禁止的启动失败，未发J、无物理试验，完整失败记录保留。并非正式三跳修复验收；六次实际净空均低于20cm，正式跳跃达标0次。

**没有确认“负向pitch_rate明显、稳定地减弱或推迟”。** test前30ms四腿平均累计制动速度变化下降16.6%，但前50ms上升6.2%，加速度RMS上升15.1%，主要体现制动后移而非持续减弱。两次空中才形成后转的test，前50ms最负rate幅度比相邻baseline小约5%～9%；起点一次晚7ms、另一次早1ms。第三次test在离地前已后转，且落地后出现短时二次离地，不能丢弃。

因此不晋级、不据此确认或排除“腿制动是重要原因”。该干预只部分达成前30ms实际制动减弱，未达成整个30～50ms持续减弱；三次/组且入空状态有差异，不能给出统计显著性或净因果量。正式入口从未替换，所以无需覆写恢复；所有运行已停止，默认源代码/程序仍为原实现。独立候选源码和程序仅冻结保留为实验资料，不继续自动调参。

## 修改前源码确认

默认源文件 `src/bbot_balance_controller/src/bbot_velocity_jump_controller.cpp`：

- 3583：`air_wheel_baseline_=last_wheel_cmd_x_`，保留离地轮速度基准。
- 3597–3626：`constexpr double arrest_duration=0.060`；四关节初位置为 `takeoff_q_hip_left_ / takeoff_q_knee_left_ / takeoff_q_hip_right_ / takeoff_q_knee_right_`，初速度为当时的 `hip_vel_* / knee_vel_*`，初加速度0。
- `end_v_hip(v)=clamp(v,-2,2)`，`end_v_knee(v)=clamp(v,-4,4)`；`end_q(q,v0,vf)=clamp(q+0.5*(v0+vf)*arrest_duration,-1.56,1.56)`，终加速度0。四关节分别建立五次轨迹。
- 3964–3987 `sample_flight_joints` 按子状态采样；4563得到q_des/qdot_des/qddot_des；4602–4619的ARREST反馈增益由实际膝速调整；4644–4647还有±3Nm髋姿态辅助项；4660–4689的ARREST动力学前馈使用参考加速度，并在6689–6700与离散关节控制相加。

所以实际快速减速由参考轨迹、关节反馈及动力学前馈共同作用，不能只把±2/±4终速约束直接等同于实际制动力矩。

原五次轨迹来自 `flight_trajectory.hpp:45–92`：u=clamp((t−t0)/T,0,1)，q=Σa_i u^i，qdot=(a1+2a2u+3a3u²+4a4u³+5a5u⁴)/T；a0=q0，a1=v0T，a2=acc0T²/2，Dz=qf−a0−a1−a2，Dv=vfT−a1−2a2，Da=accfT²−2a2；a3=10Dz−4Dv+Da/2，a4=−15Dz+7Dv−Da，a5=6Dz−3Dv+Da/2。

## 唯一实验改动

修改前已向用户说明，仅在独立副本 `sample_flight_joints` 的ARREST分支约3967行加入以下同一个轨迹形状修正，未改轨迹初始化或状态机。完整可审补丁：[test_source.patch](test_source.patch)。令Δv=v0−vf、T=0.060：

```text
baseline: q=q5(u), v=q5'(u)/T, a=q5''(u)/T²

test:
q = q5(u) + Δv*T*u³*(1−u)³
v = v5(u) + Δv*(3u²−12u³+15u⁴−6u⁵)
a = a5(u) + Δv/T*(6u−36u²+60u³−30u⁴)
```

修正项及其一阶、二阶导数在两端为0；同样初态下初末q/v/a和60ms时长均不变。最终构型和终速公式不变；没有简单延长轨迹，因为固定终点下延长时长不保证早期减速更小。未触及TUCK/EXTEND轨迹、gain1.60、THRUST、离地判定、轮限速或落地控制。前半段减速变弱、后半段可能更强，是此单逻辑干预的已知限制。

七次历史入段状态共28条参考曲线离线端点检查通过，未增加参考峰值速度或位置范围。**这仅为代数检查，不是物理验收。** 新test参考速度与新公式匹配，三次最大残差约0.000072/0.000140/0.000051rad/s；baseline与旧公式匹配。未匹配公式的平均残差约0.20～0.29rad/s，确认新程序实际作用于参考，而不是只改了入口名。

## 冻结与实验条件

两组分别独立重编译同一当前源码副本、相同头文件和无优化C++17编译选项，仅上述控制器补丁不同。构建目录为本地 `build_arrest_early_decel_baseline/bbot_balance_controller/` 与 `build_arrest_early_decel/bbot_balance_controller/`。正式 `build/`、安装入口、默认源码均未替换。私有launch仅固定原工作区路径和选择各组绝对可执行文件，其他launch内容相同。

每次发J前dump实际ROS参数，与此前baseline完整参数比较，只允许 `jump_log_path`/`jump_summary_path`差异；`landing_capture_gain=1.60`，其余全部相同。运行中前后152个冻结文件哈希一致；原先54个正式源码/程序/模型/参数文件仍完全一致。物理世界 `native_command_observation_world.sdf` 的max_step_size=0.001、real_time_factor=1.0，没有降低速度或倍率。所有原生接触时间步连续1ms，0～80ms四腿原生状态有效。

状态切换条件及时间常数未改。实际进入TUCK的时间可以因实测状态而变化，这也是干预的下游结果；不能把实际时长不同描述成设置了新状态机时序。T2在干预开始前已明显后转，不能把其离地前状态差异归为新ARREST控制的直接效果。

固定协议：[PROTOCOL.md](PROTOCOL.md)。保留既有启动稳定门+连续1秒条件，不修改门；每次独立新世界，跳一次，首触后固定观察20秒。B1在约1.4s发J，其他约7.2s，是同一启动门实际满足时刻不同；B1发J前pitch约0.0285rad，其他约0.00525rad，入空姿态/腿速也不完全匹配。因此这是小样本探索性A/B，不能当同初态确定性反事实。
