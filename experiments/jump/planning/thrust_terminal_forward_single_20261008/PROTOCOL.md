# THRUST释放段局部前向参考单次实验

唯一问题：减小释放段前向轮速要求，能否减少负外部角冲量并保留20cm净空与可接受落地。对照为已保存高跳T1，不新增基线。

唯一代码变量：现有thrust_release_.active()时，共同前向参考从0.45减0.02至0.43m/s，只用于thrust_forward_cmd_mag的前馈/速度误差；其他时刻原式。原姿态项含taper仍使用原全局目标，运动学补偿、腿部输出、限制、释放0.78、状态切换和空中/落地控制均保持。源diff保留于test_source.patch；只改独立副本，仓库默认始终为原实现。

原T1释放13.765s，持续无接触首帧13.781s，有效接地释放窗口16ms。v_pred0.550–0.557m/s，原m0.331–0.321，无0/0.85夹限；轮目标0.019–0.029，无±1.5夹限。选定减0.02在固定反馈回放下使目标和最终命令增加0.044m/s，入口从上一条0.05172至0.063454只增0.011734，小于原5ms正向slew0.08；不施加大反向命令，不扫描。回放不是闭环预测。

边界：THRUST直到控制器确认完全离地才退出，原T1在真实离地后还发布约14ms THRUST命令；本实验不改该条件。FLIGHT原逻辑air_wheel_baseline_=last_wheel_cmd_x_，首帧原限步0.25，因此参考干预会经既有继承影响空中基准，不能声称干预物理作用严格止于真实离地。保留原继承，不额外重置，不改ARREST。

运行条件：独立build_thrust_terminal_forward_single、独立test.launch.py，仅替换控制器可执行文件；启动参数0.32/0/0.78/1.60，运行参数除两个日志路径必须与T1一致，运行模型URDF/SDF一致。冻结原155项与独立源/程序/入口；新世界、RTF设置1.0、物理步1ms、原1s站立门。只发一次jump，真实首触后被动记录20s用于后退/恢复判定。原保护自主退出不改；异常时不追加命令或试次。启动失败也保留并报告，不静默替换。

性能仅计正常ARREST/TUCK/EXTEND完整跳跃；保护展腿/EMERGENCY上的高度仅诊断。分析THRUST全段/最后20ms外部冲量、总H、vz和净空、首触/恢复，实际轮速度、输入达到时序。无效/缺失保持invalid。完成一次即停止，不提交/推送，默认仍0.25/0/0.78/1.60，无论结果不采用实验实现。
