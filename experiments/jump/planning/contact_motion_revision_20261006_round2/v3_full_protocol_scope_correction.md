# V3 stop-metric scope correction

This note supplements the frozen V3 report without modifying its source, binary, outputs, manifest, or SHA256SUMS. The V3 control-trace result remains valid as a **MODEL ONLY** `MODEL_STOPPED`/trial-transition replay for the two modeled state ages; it does not qualify physical timing or authorize a live run.

The V3 stop-distance/time metrics were anchored incorrectly. In the source, `stop_start_q` and the axle start position are set when `trial_elapsed >= 1.5 s`, which is the point where quiet-dwell accounting is reset. The protocol's normal-stop trigger is at `trial_elapsed >= 1.0 s`, when reference deceleration begins. Therefore the reported `0.255 s` is only the interval from the end of the deceleration reference to quiet-dwell completion (including one extra 5 ms control tick). It is **not** the full normal-stop duration or stop distance. From the 1.0 s trigger through the reported completion, the elapsed model interval is 0.755 s.

The V3 `stop_joint_excursion`, conservative range/span, reverse excursion, axle excursion/span, and stop-time values must not be used as full stopping metrics. In particular, the recorded `0` reverse excursion is not a trustworthy full-stop rebound measurement because its direction and extrema interval start at 1.5 s. The V3 replay's quiet check and control-tick trial transition remain as logged; this correction does not invalidate its trial-control trace, but the stop metrics are not trusted.

A future V4 must anchor stop q/v, axle position and initial-velocity direction at the 1.0 s normal-stop control event; accumulate joint and axle extrema on each 1 ms model step through completion; and retain the 1.5 s quiet-dwell reset without resetting the distance/time anchors. Quiet checks and trial transitions remain on synchronized selected-state 5 ms control ticks. Do not run V4 until the fast candidate is ready; then combine this metric correction with the separately approved timing-range coverage. Until that validation is complete, V3 is not live-run qualified.
