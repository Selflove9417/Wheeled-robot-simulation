## 1. H重建：输入与公式

复现程序：[observe.py](observe.py)、[plot.py](plot.py)。原始/派生CSV及曲线为本地资料：`src/bbot_balance_controller/src/data_logs/flat_jump_trials/thrust_input_authority_20261008/`。`provenance.json`记录原始输入哈希及155项冻结一致性；`summary.json`保留全部误差和时间偏移诊断。

原始资料：B1/B2/B3位于`.../flat_jump_trials/clearance_apex_ab_20261008/physical/`，T1位于`.../flat_jump_trials/thrust_height_032_ab_20261008/physical_runs/T1/`。每次使用自身的`actual_robot.urdf`、`actual_robot.sdf`、`engine_frames.csv.inertials.csv`及`velocity_log.csv`；原生比较参照为`.../flat_jump_trials/thrust_momentum_budget_20261008/{B1,B2,B3,T1}/steps.csv`，不是重新仿真。

从实际URDF获取六关节父子关系、原点、轴向；从实际引擎静态惯量记录读取七刚体质量、完整惯量张量与惯性原点旋转/平移。合并固定IMU后body质量9.51kg，总质量17.51kg。静态模型参数是观察器模型，不是动态link真值反馈。

传感器输入取日志中的`hip_pos_left/right`、`knee_pos_left/right`、相应`*_vel_*`、`left_wheel_vel`、`right_wheel_vel`及`pitch_rate_raw`。关节运动递推得到各刚体质心位置/速度、角速度及旋转后的惯量：

```
C = sum(m_i*p_ci)/sum(m_i)
V_C = sum(m_i*v_ci)/sum(m_i)
H_hat = -sum[ I_i*omega_i + (p_ci-C) × m_i*(v_ci-V_C) ]_X
```

包含自转和轨道两部分。pitch符号沿用实际代码`pitch_=-roll`、`pitch_rate_raw_=-angular_velocity.x`（`bbot_velocity_jump_controller.cpp:1730–1737`）；负H表示后转方向。

本轮是实际平地、共pitch轴的重建：关于瞬时COM的H消去公共平移，绕公共pitch轴的旋转不改变该轴分量，因此在统一基座坐标计算轴投影。不是混用世界/局部坐标。日志未记录完整三轴IMU快照，不宣称通过任意三维翻滚工况。

轮编码器位置相位未保存于该CSV，但实际轮质心在转轴上、惯量Ixy=Ixz=0（程序逐轮断言），循环相位从H_X中解析消去；任取零相位是解析等价，不是给缺失输入补零。轮速度仍必须存在且有限。原生动态link状态只用于H参照，没有进入重建输入。

## 4. 最终五项结论

1. **H观测器是否可信？** 该重建算法在既有平面THRUST同戳样本上可信，符号与相位核对通过；当前时刻误差及在线完整性尚未合格，不能直接启用H闭环。
2. **两个输入是否有可区分实际响应？** 未验证。已有闭环共同变化数据和名义力矩余量不能证明独立权限，未将内部髋反力矩当成外部Hdot。
3. **有可执行竖直近似零空间吗？** 未验证，不能指定B、零空间方向或增益。瞬时矩阵与窗口积分响应都没有通过独立辨识，二者均不冒充已验证模型。
4. **在哪些支撑状态/时段有效？** 本轮H误差结论只覆盖已有平地THRUST配对样本；没有任何经验证的输入响应支撑域或工作时间区间，更不能外推到单轮、滑移或接触转换。
5. **能进入协同控制原型吗？** 证据不足。停止这套二输入主动协同路线；本轮无控制修改需要恢复，默认实现保持原样，保留全部原始/派生记录，完成后停止。
