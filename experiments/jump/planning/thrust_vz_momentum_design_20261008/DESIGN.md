# THRUST竖直速度—离地总俯仰角动量：最小协同设计

2026-10-08。本轮仅源码及B1/B2/B3/T1既有物理证据审查，无控制修改、仿真、构建或扫描。默认0.25 / 0 / 0.78 / 1.60不变。

**决策：最小候选为保留轮速度控制，在原THRUST内用“髋姿态补偿修正＋膝竖直推力修正”做一个有界二输入协同分配。公式可编码，但当前缺少可信的接触约束输入响应矩阵，尚不能批准为可实际启用的控制方案。** 不把目标到接触力的代数关系当作执行器可控性，不指定未经识别的增益/干预幅度。若不能补齐下述响应能力，停止，不用现有离线分配器冒充通过版本。

## 原结构、余量与约束

实际入口为`src/bbot_balance_controller/src/bbot_velocity_jump_controller.cpp`。

- 2972–3116：COM竖直速度误差＋原Bezier推力，经过姿态衰减、释放、行程保护，产生每腿Fz请求；原释放比例0.78及全部条件保留。
- 3130–3197：高度五次轨迹/IK构型参考，膝速度逆解使用质量加权COM几何与髋/机身参考速度。
- 3216–3349：每髋姿态力矩`clip[-0.5*(70*e_pitch+12*e_rate)+reaction_ff+已有修正,−20,20]`；构型PD另受−3～3限制，后转条件下下界为0。髋竖直力分担为0，膝为`Fz*Jk+原PD/制动`。
- 3427–3473：速度预测→前向速度目标＋姿态项＋运动学补偿→原±1.5和8/16变化率限制→`/diff_drive_controller/cmd_vel`。轮端接受速度，不是可自由优化的轮力矩。实际电机力矩未知，不把JointState全零effort当真实力矩。
- 3414–3422、6614以后：唯一腿力矩发布通道`/leg_effort_controller/commands`；THRUST专用PD已经计算，通用下发PD系数为0，不能重复叠加。

四次实际THRUST接触积分（kg·m²/s）：B1/B2/B3的竖直力臂项−0.408/−0.512/−0.429，水平力项−0.727/−0.734/−0.813；T1为−0.486和−1.276。T1离地H−1.633，基线−1.038～−1.151；T1离地vz2.436m/s、净空23.96cm但首触−14.60°、后退153.46cm。基线不是合格落地模板。

T1实际启动`sim_relax_thrust_limits=true`：`current_effort_limits()`在该工况返回髋/膝150/150Nm，非默认实机75/60；`thrust_torque_margin=0.95`，姿态预留8Nm。真实步输入峰值髋5.27、膝81.56Nm；因此有名义总力矩余量，但髋构型PD已截为−3/0，不能据总限幅剩余量推断构型可跟踪。实验必须保留实际原限制；不得把本工况余量外推到75/60Nm实机。

## 目标、反馈与接触力关系

目标1沿用原离地竖直速度目标和原速度闭环，**不再调整jump_height或释放阈值**。目标2新增有符号系统总H目标轨迹，抑制实际负外部角冲量；不是将body pitch_rate归零。

同一时间戳下估计：

`H_hat = -sum_i [ (R_i I_i R_i^T omega_i) + (r_i-C)×m_i(v_i-V_C) ]_worldX`

只需IMU姿态/角速度、六关节编码器q/dq、实际模型质量/惯性/几何。刚体整体平移在关于COM的H中抵消；不需要接触力传感器。COM竖直速度由现有`centroidal_height_`路径提供。传感器实际话题为`/imu`、`/joint_states`、`/model/bbot/odometry`，最后一项目前是仿真真值来源，实机需要等价基座状态估计，不能声称已有实机估计器。

可以复用`ground_angular_momentum.hpp:189,258`的完整关节历史与时间配对思路，但该观察器尚未接入当前velocity入口，CAD质量/惯量及符号必须与既有七刚体算法核对；其`momentum()`无效时返回0，调用者必须先检查valid，不能把0用作反馈。该文件部分现有目标helper只接受非负目标，不能直接传负H目标。原生物理link状态只用于验证，不进入未来实机反馈。

令`e_H=H_goal-H_hat`，需求为`M_req=H_ref_dot+k_H*(H_ref-H_hat)`，k_H及目标轨迹必须受可达性约束，当前不指定数值。基线−1.038～−1.151仅是第一轮“回到已有角动量量级”的诊断参照，不是合格首触/恢复的H_goal；不能凭它承诺20cm与稳定落地。

接地期间：

`M_pitch = -(p_y-C_y) Fz + (p_z-C_z) Fy`

给定Fz时，形式上`Fy_req=[M_req+(p_y-C_y)Fz]/(p_z-C_z)`。这条式子**只用于离线需求可行性检查**，不直接控制轮速或当作已实现的Fx指令。接触点/真实wrench由Gazebo日志用于检验；未来控制不能默认能读取它们。圆轮平地作用点可由模型与支持估计近似，但滑动、单轮接触或地面不确定时不可沿用。

## 最小二输入协同公式

保留原轮速全过程，以避免引入未知轮伺服力矩作为第三自由输入。仅选择：

`u = [delta_tau_body_per_hip, delta_Fz_per_leg]^T`

所有原PD、膝制动和反作用前馈仅算一次，作为名义输出。新的总姿态补偿在原±20Nm内，Fz仍经过原预算、力斜率、释放和行程保护。**不是放宽构型PD，也不是再叠加一个独立H控制器无限抢力矩。**

局部模型应为：

```
[delta_a_COM_z, delta_Hdot]^T = B(x, support, wheel_servo)*u
B = [[b_zh,b_zF], [b_Hh,b_HF]]
```

B必须来自包含实际轮速度约束、腿质量/惯性和接触状态的响应，不允许设成对角矩阵；b_Hh也不能设为“两个髋反力矩所以等于±2”。后者只是内部作用反作用，没有证明外部总H变化。

最小分配用解析一维竖直零空间，不引入MPC或迭代QP：

```
n = [b_zF, -b_zh]^T
u = n * (M_req-Hdot_nominal)/( [b_Hh,b_HF]·n )
```

实际实现先按每个输入的可用范围归一化，避免Nm与N混合尺度影响数值。只有该分母可靠非零且符号已验证，才存在保持名义竖直加速度的一阶H调节方向。名义竖直闭环继续产生Fz基值，无需再增竖直速度增益。

将一维系数限制在**两个输入全部现有约束的交集**：髋姿态±20、最终髋/膝实际力矩预算、膝速度15、关节范围/行程缩放、每腿Fz原斜率1600N/s、原释放力上界。求解和限制必须作用于最终合命令；不得分配后再被不同clip截断而仍声称竖直零空间成立。

若需求不在交集，报告`H目标不可达`和实际残差，不提高力矩、不牺牲原竖直安全限制、不积分累积、不把削弱需求称完成。原姿态反馈作为名义/约束，若修正引发姿态趋势或与其冲突，原保护优先、试验失败；不能用H改善否认机身姿态退化。

## 为什么必须提前协同、不能只修末段

T1最后20ms只有4.420N·s竖直接触冲量，平滑改变竖直力臂来补回0.48–0.60kg·m²/s需约26–33cm位移；这已被前轮量级计算排除为最小方案。候选必须覆盖更早的有效推地，不在释放瞬间突然启用。提前80–100ms时所需修正平均外部力矩约5–7.5Nm；这是**整个系统外部力矩需求**，不能除以双髋数量当作髋力矩命令。几何和执行延迟仍必须纳入B及其适用区间。

原T1已经证明该工况能提供2.436m/s与23.96cm，方案保持原竖直速度闭环，并寻求其一阶零空间方向，因此有“少损失竖直能力”的设计动机；它不证明该方向存在，也不保证实际净空不会下降。

## 目前不可直接启用的原因

1. **B缺失。** B1/B2/B3/T1是多个状态与输入共同变化的闭环轨迹，没有独立输入扰动，不能从相关性可靠识别两列灵敏度。此前轮速局部实验还有显著干预前分叉，不能补成髋/膝响应矩阵。
2. **现成接地模型不具备可引用的运动资格。** `thrust_support_dynamics.hpp`/`ground_urdf_response_model.hpp`可提供模型计算材料，但其轮加速度是规定参考，不是已证明的伺服实现；原接地运动完整协议未通过。不得因源码里已有矩阵/求解器就宣称B可信，也不重新引入之前超时的完整求解框架。
3. **合格H目标尚未建立。** 回到基线H量级仍可能首触后倾、后退；没有覆盖不同离地构型、速度与原空中控制的合格终端集合。H控制可验证减少角冲量，却不能单独保证最终落地。

因此本轮交付是带明确缺口的最小结构设计，**不是可无条件激活的实现方案**。能进入编码的确定部分是时间对齐H估计、纯解析分配及约束检查；执行通道B与目标未验证时，动作路径必须保持原实现，不能猜系数填空。若要求直接开展协同物理控制，当前证据不足。

## 接触变化、安全与一次最小验证

只在原THRUST有效支撑与原反馈新鲜、执行模式可信时允许协同计算；支撑不可信、时钟/配对无效或单轮/滑移超出模型域，不继续使用B、不重发旧修正，按原安全退出路径处理，不新增恢复框架。实际离地仍由原检测决定，不用H改变检测或延后退出。实机需要支持估计，Gazebo真值不能作为永久控制前提。

**条件验证方案，尚未授权实施：** 先用既有记录验证H估计与原生七刚体H，并检查局部模型B对实际加速度/总H变化、符号和接触条件的覆盖；若两列有效独立性仍无法确认，则停止，不启动协同跳跃。禁止用静态模型秩替代真实控制能力。

只有B、单一有界干预幅度和目标冻结后，才考虑一次独立高跳T1匹配条件实验（0.32/0/0.78/1.60，其余原配置），无基线重跑、无扫描。主验证：执行修正实际到达→接触角冲量减小→离地总H减负；同时保持必要竖直冲量/速度，并检查同帧双轮净空≥20cm、正常空中三阶段、真实首触pitch/rate、后退与恢复。少量内部状态改进不能替代外部角冲量。

原保护、异常碰地、二次腾空、EMERGENCY或落地恶化即失败；B符号/响应不符、零空间竖直残差过大、实际修正被截断、净空不足20cm、初态已明显分叉致归因不足，也结束、不补跑或自动调参。单次即使改善只算初步证据，不采用默认；最终每次20cm仍需后续独立重复验证。

本轮到此停止，等待批准；未提交、未推送。
