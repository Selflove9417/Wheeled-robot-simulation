# THRUST构型与接触作用线：有限工程可行性判断

2026-10-08。只读已有B1/B2/B3及原高跳T1；新增物理实跑0，未改控制器/参数/模型，未运行仿真、构建、扫描、提交或推送。默认0.25 / 0 / 0.78 / 1.60保持，155项冻结一致。0.32仅用于已有失败T1分析。

## 三个问题的结论

1. **改变推地构型具有外部力矩调节能力吗？** 物理上有：COM与真实接触作用线之间的相对位置进入外部力矩，不只是内部角动量交换。但目前没有独立控制该位置的已验证输入。髋构型PD已被限制在−3或0Nm，机身姿态补偿又与轮速、膝逆速度及姿态保护耦合；不能将目标变化直接等同实际COM位移或总H改善。
2. **所需变化现实吗？** 最后20ms补偿0.48–0.60kg·m²/s，需要已存在的水平力臂改变10.86–13.57cm；若平滑从零建立，需终点26.39–32.99cm。条件几何对应髋增量约−0.80～−1.00rad、增量峰速75–94rad/s，不是现有限制下合理末段修复。提前80–100ms时条件几何降至髋−0.10～−0.16rad、COM相对轮轴约3.2–5.2cm，关节位置上可能容纳，但未证明现有髋输入能跟踪，也未证明保住竖直冲量和接触。
3. **有可直接实施的最小修改点吗？** 本轮没有证据支持。现有髋目标入口和姿态补偿位置已精确定位，但目标偏置在PD饱和时可能根本不改变输出；改姿态参考/增益也同时影响轮端及安全门。**停止已有髋目标/姿态参数的单点修复路线，不建议开展其参数试验。** 若将来另行设计，需要显式接地构型参考与膝竖直速度一致的协调执行，超出本轮最小修改边界；本轮不开展此设计，也不扩大诊断。

`M_pitch = -(p_y-C_y)*F_z + (p_z-C_z)*F_y`

## 真实模型下的髋运动量级

从T1实际URDF、七link质量/惯性原点和每步原生link pose计算几何位移，不使用手猜连杆或质量。模型总质量17.51kg；髋轴为实际joint axis +X。条件构造为：记录的机身姿态与膝角不变，左右髋同步扰动；整腿绕实际髋轴旋转，再平移整个系统使两轮轴保持记录位置。用真实link COM质量加权求系统COM变化。左右微小不对称取双轮平均锚定，因此这是对称平面条件几何，不是动力学执行预测。

计算同时保留COM高度变化对水平力矩的影响：

`ΔJ = ∫[Fz*ΔCy - Fy*ΔCz]dt`

保持原接触点和接触力，反解达到+0.48～+0.60的单一髋平滑增量。没有计算新接触动力学、执行器跟踪或闭环姿态，因此不得认定以下轨迹能实际完成。

## 实际控制入口与为什么不能直接改一个目标

实际源码：`src/bbot_balance_controller/src/bbot_velocity_jump_controller.cpp`。

- 2840–2845：`thrust_pitch_reference(jump_pitch_ref_,jump_takeoff_pitch_rate_,thrust_pitch_rate_lead_time_,thrust_motion_elapsed_)`。helper在`jump_phase_control.hpp:32`：`u=clamp(t/T,0,1)`，rate=`rate0*(1−3u²+2u³)`，angle=`angle0+rate0*T*(u−u³+0.5u⁴)`。实际初值jump_pitch_ref0.05、rate0.05rad/s、T0.07s，后段目标保持0.05175rad，角速度目标0。此为机身姿态目标，不是COM/轮轴位置目标。
- 3130–3159：五次高度轨迹→`inverse_kinematics(target_ik_z,0.0)`→`q_hip_des`/`q_knee_des`。原IK来自`src/bbot_kinematics/src/kinematics.cpp:70`起，固定CAD髋轮Y偏置，非独立水平COM目标。名义时长thrust_duration0.24s；实际离地前运动进度并未走完。若出现原`grounded_thrust_hold`则目标退到实测关节位置；本轮不能将此分支误说成T1末段始终执行。
- 3153–3174：髋参考有限差分限速3，释放制动缩放。3184–3193：膝逆速度引用髋名义速度及机身角速度参考；实际构型进入竖直Jacobian。因此只改髋轨迹而不检查这条链，会改变膝所需运动/竖直能力。
- 3216–3220：`tau_body_per_hip=clamp(-0.5*(70*pitch_err+12*pitch_rate_err)+reaction_ff,−20,20)`，还有原膝制动/快速rate修正。
- 3224–3245：髋PD=`clamp(18*(q_des−q)+2.5*(dq_des−dq),pd_h_min,3)`；当原反馈pitch_rate<0或pitch_err<0，`pd_h_min=0`，否则−3。3256髋竖直力分担固定0，最终输出为姿态补偿+受限构型PD；膝承担Fz*Jk。3370以后原终端髋floor关闭。
- 3427–3459：同一pitch/rate误差也进入轮端速度反馈；2880–2969、3040以后姿态趋势还会冻结运动或降低Fz请求。改姿态参考会同时改变轮控和保护，不能称独立髋构型调节。

## 竖直冲量与姿态风险

固定接触力计算只是必要量级，不包含新构型对Fz/Fy的改变。实际膝力臂、速度逆解和力预算都依赖髋角/机身角；髋提前制动可能降低竖直速度、改变接触中断/再次接触、触发原姿态门，也可能引入空中残余角动量和首触风险。80–100ms小幅几何变化的终点高度变化虽小，不能据此认定动态竖直速度不损失。

没有足够证据支持一项现有目标/增益的最小控制修改。保持默认，结束该单点路线；不进入新仿真或更大根因调查。
