# 空中阶段重新分配：条件式最小设计，尚非执行资格

2026-10-08。仅源码、已有 B1/B2/B3 默认 Gazebo 数据及离线轨迹/刚体计算。新增物理运行0，未修改控制器、参数、保护、launch 或构建产物；不提交、不推送。默认控制及 landing_capture_gain=1.60 保持。上轮延后 EXTEND 候选不采用，本轮也不是重新尝试“等最高点”。

## 决定

**有一个保留反向保护的空中局部方案，但目前只能确认条件式参考轨迹可行，不能确认现有控制器能按时产生实际有效收腿。** 最小结构是“连续制动 → 有限参考保持/跟踪收敛 → 一次受保护的有效收腿 → 连续展腿”。保持 THRUST、ARREST 原目标与入口、轮控制、落地捕获公式及限制不变；需要联动修改 TUCK 内部段计划和 EXTEND 完成判据，不能只加时长。

一次现有 knee 0.04rad 步幅允许的收腿量只有约6–7mm腿轴距、约4–5mm轮轴相对COM高度，远不是数厘米净空收益。不能承诺最大双轮净空因此提高同样数值。当前主要未知是能否在约65ms内消除原有0.15–0.18rad膝跟踪误差，同时形成允许下一段的实际运动状态。没有这项证据，不能把设计称为可安全进入A/B的完整方案。

## 2. 候选目标与最小动作量

不改 `reaction_safe_configuration_step` 的阈值0.50、hip步幅0.14、knee步幅0.04。高残速下仍只制动，不生成反向收腿；新增收腿必须在实测状态经同一helper确实允许后才尝试，不能用参考零速替代实测速度。

在原TUCK终点参考q_b处的一次最小结构候选：

1. 用当前CAD关节几何把 `q_k,b + 0.04` 映射成新的平面腿长目标。这里0.04取现有单次步幅上界，**不是宣称非零收腿存在数学最小幅度**；再小的动作当然可构造，但不构成有意义的净空方案。左右独立计算、保留原有微小侧差。
2. 膝目标决定长度；髋用同一七刚体模型的一阶相对角动量抵消关系协调，不简单照搬固定高度IK：
   `Δqh = -[e_x^T R I_locked^-1 A_k]/[e_x^T R I_locked^-1 A_h] * Δqk`。
   `A_h/A_k` 是左右同类关节单位速度产生的完整相对角动量，包含轮刚体被腿带动的轨道/自转项。计算得到比值−0.5030～−0.5051，即每髋约−0.0201～−0.0202rad、每膝+0.0400rad。最终落地构型仍用原EXTEND公式，不改变landing控制。
3. 目标仍必须以**实测**q/dq经过原helper限幅/反向检查。若保护改变目标，重新做几何、角动量和整段准入，不把这里的理想目标直接下发。若结果未比当前和参考构型都更短，跳过有效收腿，不靠重复调用突破步幅。

## 3. 轨迹连续性与执行约束

复用 `QuinticTrajectory::init(t,T,q0,v0,a0,qf,0,0)`；一般系数保持现有实现，段间先 `sample_flight_joints()` 得到旧参考q/v/a再初始化，保证参考C2（因此C1）。实测状态用于保护、可执行性检查与剩余时间判断，不能通过把参考瞬间重置到实测值来声称参考连续。

### 连续制动段

当前ARREST→TUCK从实测重新初始化，已有髋参考速度跳变−1.47～−2.14rad/s，膝+0.78～+1.14rad/s。候选在原切换时刻采样ARREST参考q/v/a，以原保护后的实测q_b为制动终点、末速/加速度0，仍60ms。既有ARREST轨迹、切换时刻及终点保护不变；仅改空中段接续的初边界。

使用真实入口和解析五次极值检查，C2接续后的hip峰速3.63–4.17、峰加速度247–300；knee峰速6.62–7.21、峰加速度411–459，低于现有11/13、450/500。最大膝位置绝对值≤1.413rad，低于1.57硬限位。起点加速度沿用旧段而非强制清零。实际状态出发的旧制动路径也必须仍通过同一检查。**这只验证参考，不证明修改边界后的实际制动和角动量响应不变。**

### 收腿段与保持

理想q_b/零速/零加速度到新q_f，使用 `s(u)=10u³−15u⁴+6u⁵`，`q=q_b+Δq*s(u)`。

- 解析最短5ms网格时长25ms；膝解析极值为 `a_peak=(10/sqrt(3))*0.04/0.025²=369.50rad/s²`，`v_peak=3.00rad/s`。
- 候选选40ms而非压到边界；膝峰速1.875、加速度144.34，髋约0.943–0.947、72.6–72.9，均未放宽限制。
- 原生模型Newton–Euler反算理想收腿段内力矩：髋峰约1.13–1.27Nm，膝8.48–9.37Nm，低于飞行75/60Nm。是1ms有限差分内部样点的**模型值**，不是实际执行力矩或全段上界资格。
- 控制器TUCK为kp_hip=12/kd_hip=1.5、kp_knee=15/kd_knee=1.5；实际进入 `discrete_flight_pd`，horizon按样本周期/年龄限到0.025–0.060（cpp6665–6678、flight_joint_pd.hpp）。ARREST动力学前馈只在ARREST，不能假定新TUCK获得反算力矩。未饱和≠能跟踪40ms段。

原60ms制动结束时实际膝仍落后参考0.146–0.184rad。因此需要有限保持/连续重规划，使实测保护结果及目标几何有效。参考保持q_b/0/0不造成跳变，但实际何时跟上未知。不在本轮虚构新的误差门限或拿“参考末速0”替代实际收敛。新收腿/EXTEND均从旧参考解析边界接续，同时以实测边界检查同一终点；任一失败或deadline先到则保留既有展腿/保护优先级。

EXTEND仍锁存原capture目标，保持原速度/加速度/关节限位和wheel-first投影；若投影激活，最终发布参考也需复核连续性，不能只检查投影前五次式。候选名义构型小腿角在当前约0.75rad锥内，但新运动下的姿态及投影是否触发未获物理证明。

历史COM最高点前的保持上限约69/70/69ms，按5ms网格保守取65ms；新收腿不需要等最高点。仅以最低90ms展腿加55+20ms预算算，保持上限93/105/93ms，但那会错过本轮提高最高净空的有用窗口，所以没有用它强行扩大TUCK。

同次历史landing_target_x目标的零端速展腿最短运动学网格时长90ms；候选135–210ms仍大于该下限。各候选展腿hip峰加速度≤52.4、knee≤15.6rad/s²。不过这不是触地安全证明：实际触地时间随姿态/腿构型变化，原弹道估计已有约25–27ms裕度偏差；新capture锁存时刻也推迟，届时的速度和landing_target_x必须重算，不能把历史目标当必然值。55ms既有限制原样保留，不能按历史表替代实时预算。

**必要联动修改，不能拆开：**

1. `plan_tuck_round_trip` / `FlightRoundTripPlan` 的单一mid计划要覆盖制动、有限保持、有效收腿、EXTEND完整边界和总预算；否则新增段不在准入内。
2. `begin_tuck`用旧ARREST参考接续制动；TUCK内须区分制动结束与有效收腿结束，增加局部段索引/时钟，复用现有轨迹容器即可，不新建控制框架。
3. `tuck_finished`必须表示整个TUCK动作完成。只延长一个duration仍会得到qf=q0；只加收腿段不改完成判据会在原60ms直接EXTEND。
4. EXTEND保留原deadline、最长可行时长搜索及落地目标公式，但初值用旧参考解析值保证C1，并额外校验实测可达性。否则新增动作会再次在重锚到实测时产生跳变。

这已是空中轨迹边界/分段的联动设计，不是一个参数修改。未实施，也不涉及THRUST、轮控制增益或落地控制调整。

## 5. 角动量评估及不可推导之处

复用此前验证的七刚体方法：每link自转 `I_world*omega` 加系统瞬时COM处轨道项 `(r-C)×m(v-V)`；完整三维统一世界系，全部7link，模型质量/惯量/惯性原点取本次实际URDF和引擎inertials清单。独立原生状态在原EXTEND入口核对 `H=I_locked*omega_body+H_relative`，残差约1e−15～1e−14，验证运动学/惯量转换一致。

条件收腿段保持同一总H，轮相对转速保持该入口实测值，积分机身刚体姿态。**这是冻结轮速的敏感性情景，绝不是预测原轮控制器会保持该速度。** 改动腿轨迹后轮控制的反馈输出可能变化。本段假设已先完成实际收敛，未模拟那段收敛或改变后的早期制动。

模型总H固定是计算假设，代数残差不是新物理守恒验收。预测COM弹道相同也不是新真实高度结论。曲线均标注MODEL，不绘制虚构实际扭矩。

## 6. 本轮交付及停止

设计候选只能作为下一步审查对象，**尚不能宣布实际有效收腿及首触稳定性可行**。明确缺少：有限保持期间的真实跟踪收敛时间、连续制动改动后的角动量实际响应、冻结轮控制下的闭环响应及新EXTEND实际完成裕度。已有日志不能补齐这些反事实数据。当前不建议仅依据几何上约4–5mm潜在净空收益直接采用。

[计算程序](calculate.py)及[连续制动解析检查](continuous_brake.py)可在工作区只读复算；输出本地资料 `src/bbot_balance_controller/src/data_logs/flat_jump_trials/airborne_reallocation_design_20261008/` 的 summary.json、continuous_brake.json、conditional_model.csv/png、calculation.log、provenance.json。保留上轮原始数据路径。冻结清单核对及文档记录不属于控制修改。完成后停止，等待批准；不自动构建、仿真或调参。
