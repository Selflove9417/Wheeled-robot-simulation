# 有限支撑恢复轮（2026-10-07）

问题：低速接地候选出现计算拒绝等故障时，在直接状态、实际输入、双支撑和独占所有权可信的条件下，能否从真实 q/v/u 连续进入有限协调减速并停止终止？

改动：独立接地候选增加恢复控制与状态机；独立监督增加恢复总期限。复用原 manager、状态／接触连续锁存和停止候选边界，正常候选输出准入拦截保留到独立检查完成。默认 velocity 跳跃、其他控制器、原限幅、状态年龄和时限不变。

通过条件：
- 有实际可执行的独立恢复路径，真实初态／实际输入连续交接，髋膝与轮协调；恢复不是重发最后力矩、清零支撑或回旧 PD。
- 原同档 0.5 s 减速、0.25 s 安静确认及总 2 s 墙钟有限终点；无论恢复成功与否故障试次仍 FAIL，停止后暂停终止不自动继续。
- 不可信条件、停止越界、恢复逆解拒绝或超时立即锁输出并独立暂停；短暂接触恢复不得清除故障。
- 单测、固定模型故障协议和完整候选接管的无运动 ROS 注入分层核对；不能靠辅助单测或暂停 stub 声称物理恢复。
- 准入全部通过后才允许接审过的正常候选控制律，并按已授权固定协议最多一次受限接地标定；失败不立即重跑，不试跳。

本轮保留全部旧修改、冻结、原始数据与失败。必要构建、针对性测试与无运动 ROS 集成已授权。不提交推送；本轮验收后报告是否具备接地标定条件。

用户后续要求“做完这轮停下”：本轮仅完成实现、独立审查与上述无运动检查，验收后停止；即使准入通过也不自动启动接地标定或试跳。
