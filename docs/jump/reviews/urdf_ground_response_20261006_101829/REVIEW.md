# 固定 URDF 参数模型核对：FAIL

问题：实际重力和固定 IMU 是否解释持续支撑响应残差。只改独立离线预测器，未改控制器或做新实跑。三种源码固定配置对两份记录各保留全部5000步、前后各2500步；全部六项均未过原响应门。

修正近零静/滑摩擦边界后，两份记录均无拒绝帧，但轮部相对 RMS 仍约0.37–0.51，七个其他自由度通过不构成九维通过。重力及固定IMU修正未解决此问题。

后续物理原因审查发现，DART先做含隐式阻尼的自由动力学，再以普通惯性处理接触/关节摩擦冲量；本轮模型将其合并。三个固定点用实际 q/v/u 单独计算自由速度后的轮阻尼，与原生关节合负载相差最多1.18e-7Nm；该比较仅为旁路诊断，未用于预测器输入，也不是响应门通过。见 [诊断](fixed_time_free_damping_diagnosis.json)。

另发现 Gazebo 的 ECM 基座状态受 ChangedWorldPoses 的1e-6变化阈值影响，尚不能证明每步原生状态新鲜。原数据完整性通过只说明键、分量和连续性；完整原生九维验收需补物理引擎直接读取核对。
